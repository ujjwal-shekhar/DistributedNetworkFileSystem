# Contributing to OrionFS

Thank you for your interest in contributing to OrionFS!

## Getting Started
1. **Clone the repo.**
2. **Build the project:** Use `./quick_build.sh` or standard CMake commands.
3. **Run tests:** Verify your changes with `ctest` or the individual unit test executables.

## Pull Requests
- Ensure all tests pass.
- Maintain the C++26 standards and module-based structure.
- Document any new features or API changes.

## Code of Conduct
Please be respectful and collaborative.
